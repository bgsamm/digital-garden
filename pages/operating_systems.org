* Overview

This page contains a reimplementation of the MINIX 3 operating system,
developed alongside the third edition of "Operating Systems: Design
and Implementation" by Andrew S. Tanenbaum.

** MINIX 3 architecture

MINIX 3 is divided into four layers:
1. The kernel (including the clock and system tasks)
2. Device drivers
3. Server processes (process manager, file system, etc.)
4. User processes (including init)

Only processes in layer 1 may use kernel mode instructions; all other
layers run in user mode.

* Layer 1: The kernel

The kernel is responsible for scheduling processes and managing their
states (ready, running, or blocked), as well as passing messages
between processes. It also provides access to I/O ports and
interrupts, since modern processors require use of kernel mode
instructions for these operations.

** The clock task

The clock task interfaces with the hardware that generates timing
signals; it is not accessible to user applications and interfaces only
with the kernel.

** The system task

The system task implements the kernel calls required by user
applications in layers 2 and 3.
