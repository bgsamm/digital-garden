* Overview

This page reimplements version 4.4BSD-Lite, aka Net/3, of the Berkeley
sockets API, based on the source code description in "TCP/IP
Illustrated, Volume 2" by W. Richard Stevens and Gary R. Wright.

The code is structured into 3 layers:
1. The socket layer
2. The protocol layer
3. The interface layer

* The socket layer

The socket layer is the protocol-independent interface for creating
sockets.

#+name: socreate function definition
#+begin_src c
  <<socreate function signature>> {
      struct proc *p = curproc;
      struct protosw *prp;
      struct socket *so;
      int error;

      if (proto)
          prp = pffindproto(dom, proto, type);
      else
          prp = pffindtype(dom, type);

      if (prp == 0 || prp->pr_usrreq == 0)
          return EPROTONOSUPPORT;
      if (prp->pr_type != type)
          return EPROTOTYPE;

      MALLOC(so, struct socket *, sizeof(*so), M_SOCKET, M_WAIT);
      bzero((caddr_t) so, sizeof(*so));

      so->so_type = type;
      if (p->p_ucred->cr_uid == 0)
          so->so_state = SS_PRIV;
      so->so_proto = prp;

      
  }
#+end_src
