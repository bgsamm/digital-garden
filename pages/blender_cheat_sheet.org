#+INCLUDE: ".global_options"

* Keyboard shortcuts

** General

| Shortcut | Action                  |
|----------+-------------------------|
| a        | Select all              |
| g        | Move                    |
| r        | Rotate                  |
| s        | Scale                   |
| n        | Toggle properties panel |
| Tab      | Toggle mode             |
| .        | Change pivot point      |
| S-s      | Move cursor             |

** Object mode

| Shortcut | Action   |
|----------+----------|
| S-a      | Add mesh |

** Edit mode

| Shortcut | Action                                       |
|----------+----------------------------------------------|
| C-r      | Loop cut (scroll to increase number of cuts) |
| M-LMB    | Loop select                                  |
| e        | Extrude                                      |
| g g      | Edge slide                                   |
| i        | Inset                                        |
| m        | Merge                                        |
| M-z      | Toggle x-ray                                 |
| o        | Toggle proportional editing                  |
